# CLAUDE.md

Entrypoint for Claude. The shared source of truth for all agents is
[AGENTS.md](AGENTS.md): project overview, tooling, standard commands
(lint/types/tests), and how to run the app locally. Read it first and follow
it; do not let instructions here diverge from it.

## Default workflow

1. Read the shared docs (`AGENTS.md`, `docs/`).
2. Inspect the relevant code before editing.
3. Plan the change.
4. Make the minimal change that solves the task.
5. Verify with the standard commands from `AGENTS.md`.
6. Report risks, limitations, and anything left unverified.
